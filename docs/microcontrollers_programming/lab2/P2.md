# Sesión de laboratorio 2: Temporizadores

**Tiempo estimado:** 1,5 h (una sesión)

## Descripción

El objetivo de esta sesión es aprender las diferentes formas en que un microcontrolador puede realizar operaciones de temporización. Como se vio anteriormente, la función `delay()` se puede utilizar para crear una espera durante el tiempo requerido. Sin embargo, para resolver problemas algo más complejos, es necesario utilizar *temporizadores*, que permiten gestionar eventos periódicos sin bloquear necesariamente la ejecución del programa.

## 1. Trabajo con hardware real

### 1.1. Uso de una biblioteca externa: _Ticker_ (temporizadores de software)

La [biblioteca Ticker de Arduino](https://github.com/sstaub/Ticker?tab=readme-ov-file) permite crear fácilmente funciones de retorno de llamada que se ejecutan en intervalos determinados. El siguiente ejemplo muestra cómo realizar operaciones de temporización utilizando la biblioteca _Ticker_ y las funciones `attach()` o `attach_ms()`.

```Arduino
#include <M5Core2.h>   // Biblioteca M5Stack Core2
#include <Ticker.h>    // Biblioteca Ticker

#define LED_PIN 14     // Pin GPIO donde está conectado el LED en el M5Core2

Ticker blinker;        // Crear un objeto Ticker. Llamará a una función en intervalos regulares.

/*
  Esta función (callback) será llamada por el Ticker en el intervalo de tiempo configurado.
  Simplemente invierte el estado del LED:
    - digitalRead(LED_PIN) lee el estado actual (HIGH/LOW)
    - ! invierte ese estado
    - digitalWrite escribe el estado invertido de nuevo en el pin
*/
void changeState()
{
    digitalWrite(LED_PIN, !(digitalRead(LED_PIN))); 
}

void setup() 
{
    M5.begin();          // Inicializar el hardware del M5Core2 (pantalla, I2C, etc.)
    pinMode(LED_PIN, OUTPUT); // Configurar el pin del LED como salida

    // Inicializar el Ticker para llamar a changeState() periódicamente.
    // attach() acepta tiempo en segundos (aquí 0.5 s = 500 ms).
    // Si prefieres milisegundos, usa attach_ms(milisegundos, callback).
    blinker.attach(0.5, changeState); 
}

void loop() 
{      
    // Vacío: el Ticker maneja el parpadeo periódico del LED de forma asíncrona.
}
```

Conecta un LED al GPIO14 del M5Core2 y modifica este ejemplo para que el LED cambie de estado cada segundo, en lugar de cada 500 ms.

### 1.2. Uso de temporizadores de hardware

Sin embargo, como se indica en la documentación de la biblioteca _Ticker_, «la biblioteca no utiliza interrupciones de los temporizadores de hardware y funciona con las funciones `micros()` y `millis()`». Esto significa que nuestra capacidad para desarrollar aplicaciones con distintas configuraciones de temporizadores o para implementar aplicaciones multitarea estaría muy limitada si nos restringiéramos a utilizar únicamente esta biblioteca.

Realiza de nuevo el ejercicio anterior, pero utiliza en este caso una interrupción generada directamente por un temporizador de hardware. Configura el temporizador para que el LED cambie de estado cada segundo y verifica con un cronómetro que funcione correctamente.
